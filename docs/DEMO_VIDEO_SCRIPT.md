# tako プロダクトデモ — 動画台本（全面改訂版）

ステータス: レビュー用ドラフト（未収録）
想定尺: 6〜7分
根拠: `scripts/demo.ts` と、実際に接続済みの Drive / Discord / Slack の
ダミーデータから引用。収録前に、コピーやダミーデータの内容が変わって
いないか実機で必ず再確認すること。

## 今、実際に接続されているもの

- **Google Drive**（`shared` ソース、3件）— スタートアップ講義メモ、
  ヒアリング用フォーム一覧、"Aletheia AI Review Desk" のリーンキャンバス
- **Discord #general**（`general` ソース、Drive と統合）— 社内の日常的な
  やり取り
- **Slack** の9チャンネル（`general` ソース、同上）— `tako-demo-` から
  始まる、部署ごとのダミーデータ:
  `announcements` `customer-support` `engineering` `finance` `handover`
  `legal` `operations` `product` `sales`
  （`hr-private` は非公開チャンネルの権限設定が未完了のため今回は対象外）

このSlackのダミーデータは秀逸で、各部署の内容がそのまま **tako自身の
統治原則**（人の承認なしに確約しない・機密情報を区別する・根拠を示す）
を体現する例になっている。台本内の具体的な引用はすべてこのデータから。

## 収録前の準備

1. アプリを起動する: `bun scripts/demo.ts`（`.env` の `ASK_PROVIDER` で
   ローカル/Gemini デモモードを選べる。収録中に切り替えるなら §3 を参照）。
2. ブラウザはフルスクリーンにし、ブックマークバーや個人のタブは隠す。
3. 収録前に通知（Slack、メール、OS通知）をすべてオフにする。
4. Approvals（承認）キューに事前に1件ダミーの提出を入れておく（§7 で
   実際にクリックできるものが必要）。

## ナレーションのトーン

「あなた」に語りかける現在形、平易な言葉。専門用語（DAG、コネクタ、
エンベディング、トークン以外の実装用語）はナレーションで使わない。

## 1. オープニング — Home（0:00〜0:20）

**画面:** `home` — "Work, connected."／"Tako handles the handoffs between
your team's tools."

**操作:** Home 画面を表示。統計タイル、Recent activity / Needs attention

**ナレーション:**

## 2. Ask Tako — 質問と部署別の絞り込み（0:20〜1:40）

**画面:** `ask`

**操作①（絞り込みなしの質問）:** Source を「General」に設定し、質問欄に
入力:
> 出張精算のルールは？

送信すると、`tako-demo-operations` チャンネルの実データ（「国内出張は
帰着後10営業日以内に申請」「30万円を超える支出には部門長の事前承認が
必要」）を根拠に答える。回答の下の引用チップをクリックして、元の
Slack投稿がそのまま開くことを見せる。

**ナレーション:**
> 「5つの違うアプリを開いて探す代わりに、ここで聞くだけです。
> 　答えには必ず、元の投稿への根拠リンクが付きます。」

**操作②（カテゴリ絞り込み）:** 質問欄をクリアし、「営業 / Sales」チップを
選択してから質問:
> 東海精密の件、何が必要？

`tako-demo-sales` の実データ（「9月30日までに提案書」「SSO・国内保管・
監査ログが要件」「SSOは要件確認中、法務確認が終わるまで確約表現は
使わない」）から、営業チャンネルの内容だけを根拠に答える。

**ナレーション:**
> 「部署ごとに絞り込むこともできます。今回選んだのは営業だけ ——
> 　同じ会社の中でも、関係ない部署の情報に埋もれずに済みます。」

**操作③（モデル切り替え、任意）:** 「Details」を開き、Model のところで
Ollama（ローカル）と Gemini（デモ用・外部）のトグルを見せる。

**ナレーション:**
> 「回答はローカルのモデルで動きます。今日はデモ用に外部モデルへ
> 　切り替えられる状態も用意していますが —— これは明示的に切り替えた
> 　ときだけで、画面にもはっきり警告が出ます。実運用では常にローカルの
> 　ままです。」

## 3. Connected Apps — 接続とトークン取得ガイド（1:40〜2:30）

**画面:** `connect`

**操作:** カテゴリ一覧（ドキュメント／チャット／ファイル／拡張／
設計・CAD）とアプリカードのグリッドを見せる。Slack のカードをクリックし、
サマリーパネルを開く。「Where do I get this token? →」をクリックして、
アプリ内にそのままガイドが開く様子を見せる（別タブや生ファイルには
遷移しない）。

**ナレーション:**
> 「アプリの接続は常に読み取り専用です。tako が Slack や Notion に
> 　書き戻すことは決してありません。トークンの取得方法も、迷わず
> 　アプリの中からすぐ確認できます —— サービスごとに、実際の手順を
> 　そのまま載せています。」

## 5. Approvals — 信頼の要（3:00〜4:00）

**画面:** `approvals`

**操作①:** 事前に用意したキューの1件を選び、詳細パネルを開く。決定
ボタン（Approve / Request changes / Reject / Ask administrator）を見せる。

**ナレーション（ゆっくり読む）:**
> 「tako の AI が作ったものが、それ単独で外に出ることは絶対に
> 　ありません。必ずここで、人の確認を待ちます。」

**操作②:** 「Protect sensitive information」までスクロール。架空の
氏名・電話番号・メールアドレスを含む短い文をペーストし、「Check for
sensitive info」をクリックして検知の様子を見せる。

**ナレーション:**
> 「そもそも審査に提出する前の段階で、機微な情報が含まれていないかを
> 　チェックします。これは `tako-demo-legal` に書かれている考え方——
> 　『公開情報、社内情報、機密情報、個人情報を区別する』が、実際の
> 　機能として動いている例です。」

## 9. セキュリティへの取り組み — 何を言ってよく、何を言ってはいけないか

これは画面をクリックして見せる項目ではない —— §5（Approvals）に
組み込むか、§8 の前に短い口頭コメントとして入れる。

**カメラの前で言ってよい内容（根拠つき）:**

- すべてのモデル呼び出しはローカルの Ollama で行われ、外部のホスティング
  型 AI サービスには送られない（デモモード時を除く、その場合は明示的に
  警告表示される）——
  `docs/PROTOTYPE_SECURITY_CHECKLIST.md` の P0-03、判定「合格」。
- API キー・トークン・`.env` の値は Git 履歴にもビルド成果物にも
  含まれていない（P0-02、判定「合格」）。
- サーバー側で不正・巨大な入力を拒否し、主要エンドポイントごとに
  レート制限がある（P0-04、P0-07、いずれも「合格」）。
- エラー応答はスタックトレース・内部パス・機微情報を利用者に返さない
  （P0-06、判定「合格」）。
- 会社としてのセキュリティ基準書（`docs/COMPANY_SECURITY_BASELINE.md`）
  があり、テナント分離・デフォルト拒否の認可・外部公開前の人による
  承認必須を、譲れないアーキテクチャ原則として明記している。
- ロールバック手順書と、実際に検証済みのロールバック用タグが存在する
  （P0-10、判定「合格」）。

**まだ実現していない内容 — カメラの前で言ってはいけないこと:**

- コネクタの認証情報は現状、この端末上の `config/connectors.json` に
  **平文で**保存されている —— 暗号化された認証情報ストアはまだ存在しない。
- CSP ヘッダーはまだ設定されておらず、XSS の自動回帰テストも
  整備されていない。
- HTTPS・secure cookie 周りは「対象外（現時点）」—— 公開先の
  デプロイ環境がまだ存在しないため。
- メンバーごとの認証・権限制御は現状まだ**設計仕様**の段階であり、
  実装されて強制されている機能ではない。

**推奨する発言例（誇張なし）:**
> 「ここまでご覧いただいた内容は、通常はすべてローカルのモデルで
> 　動いています。入力はサーバー側でチェック・レート制限されていますし、
> 　エラーが内部の詳細を漏らすこともありません。とはいえ、これはまだ
> 　プロトタイプです —— 認証情報の保存方法やメンバーごとの権限制御は
> 　まだロードマップの段階で、完成していません。それを隠さずお伝え
> 　します。」
